PREVISUALIZAR LA WEB

Opción sencilla: abre index.html en tu navegador y conserva la carpeta assets junto al archivo. La navegación y los desplegables funcionan sin instalar nada.

Opción React / CodeSandbox: importa el repositorio completo, instala las dependencias con npm ci y ejecuta npm start.

Para editar: src/App.js contiene el texto y los componentes; src/site.css contiene el diseño.

Tras editar, ejecuta npm run build:static para actualizar index.html y Prospect Biotech.html.

Para una compilación de producción React, ejecuta npm run build. El resultado estará en build/.
